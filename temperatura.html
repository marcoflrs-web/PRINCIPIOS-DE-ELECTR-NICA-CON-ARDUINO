SENSOR DE TEMPERATURA Componente

Definición

🌡️ ¿Qué es un sensor de temperatura?

Un sensor de temperatura es un componente electrónico que convierte la temperatura del entorno en una señal eléctrica medible. El LM35 es un sensor analógico de precisión que entrega 10 mV por cada grado Celsius, ideal para conectarse al pin analógico de un Arduino sin necesidad de conversión adicional. El DHT11 es una variante digital que además mide humedad relativa y usa un protocolo de 1 hilo.

Ambos trabajan a 5V, son fáciles de conectar en protoboard y ofrecen lecturas estables dentro de un rango de temperatura ambiente típico de 0°C a 100°C.

Componentes del circuito

🌡️
Sensor LM35 / DHT11
Transductor de temperatura. LM35: salida analógica 10 mV/°C. DHT11: salida digital 1 hilo.
🖥️
Display LCD 16×2
Pantalla de cristal líquido con retroiluminación verde. Muestra 2 líneas de 16 caracteres cada una.
🔷
Módulo I2C (PCF8574)
Adaptador I2C para el LCD. Reduce los pines necesarios de 16 a solo 4 (VCC, GND, SDA, SCL).
⚡
Arduino UNO
Microcontrolador que lee el sensor, convierte la señal y envía los datos al display para visualizarlos.
🔌
Protoboard + Cables
Placa de prototipado sin soldadura para realizar las conexiones temporales del circuito.
🔋
Fuente 5V (USB)
Alimentación del sistema. El Arduino provee 5V al sensor y al display desde su pin de potencia.

⚠️

Importante: Al usar el módulo I2C con el LCD, verifica la dirección I2C del módulo (normalmente 0x27 o 0x3F). Si el display no muestra texto, prueba ajustando el potenciómetro de contraste en el módulo PCF8574 con un desarmador pequeño.

DISPLAY LCD 16×2 Salida visual

🖥️ ¿Cómo funciona el display LCD?

El display LCD 16×2 (Liquid Crystal Display) es una pantalla alfanumérica capaz de mostrar 2 líneas de 16 caracteres cada una. Utiliza un controlador HD44780 internamente y se comunica con Arduino a través de su librería nativa LiquidCrystal (modo paralelo) o mediante el módulo I2C PCF8574 que reduce los pines de conexión a solo 4.

La retroiluminación verde-azulada permite ver los datos en condiciones de baja luz. Con Arduino, basta enviar cadenas de texto con lcd.print() para visualizar valores en tiempo real.

INSTALACIÓN DE LIBRERÍAS Arduino IDE

📦 ¿Por qué necesitas instalar librerías?

El display LCD 16×2 con módulo I2C y el sensor DHT11/DHT22 requieren librerías externas para funcionar con Arduino. Estas librerías ya incluyen todas las funciones necesarias para inicializar la pantalla, enviar texto y leer el sensor sin tener que programar el protocolo desde cero.

Método 1 — Gestor de librerías (recomendado)

01
Abrir el Gestor de Librerías:
En Arduino IDE ve al menú Herramientas → Administrar Bibliotecas… (o presiona Ctrl + Shift + I en Windows/Linux, ⌘ + Shift + I en Mac). Se abrirá el panel del gestor de librerías.
02
Buscar la librería LiquidCrystal I2C:
En el cuadro de búsqueda escribe LiquidCrystal I2C. Busca la de autor Frank de Brabander (o "johnrickman"). Haz clic en Instalar.
03
Instalar librería DHT (si usas DHT11/DHT22):
En el mismo gestor busca DHT sensor library de autor Adafruit. Haz clic en Instalar. Arduino preguntará si deseas instalar dependencias — elige "Instalar todo".
04
Verificar la instalación:
Ve a Archivo → Ejemplos y comprueba que aparecen las carpetas LiquidCrystal I2C y DHT sensor library en la lista. Si aparecen, la instalación fue exitosa.

Método 2 — Instalar desde archivo .ZIP

ZIP
Descargar el ZIP desde GitHub:
Ve a github.com/johnrickman/LiquidCrystal_I2C, haz clic en Code → Download ZIP. Guarda el archivo en tu computadora.
ZIP
Importar en Arduino IDE:
Ve a Sketch → Incluir Librería → Añadir biblioteca .ZIP…, selecciona el archivo descargado y haz clic en Abrir. La librería quedará instalada automáticamente.

Código de ejemplo — Temperatura en LCD

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <DHT.h>

// Configura el LCD: dirección I2C, columnas, filas
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Configura el sensor DHT11 en el pin 2
#define DHTPIN  2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  lcd.init();          // Inicializa el LCD
  lcd.backlight();     // Enciende la retroiluminación
  dht.begin();         // Inicializa el sensor
}

void loop() {
  float temp = dht.readTemperature();   // Lee °C
  float hum  = dht.readHumidity();      // Lee %

  lcd.setCursor(0, 0);                  // Línea 1
  lcd.print("Temp: ");
  lcd.print(temp);
  lcd.print(" C");

  lcd.setCursor(0, 1);                  // Línea 2
  lcd.print("Hum:  ");
  lcd.print(hum);
  lcd.print(" %");

  delay(1000);   // Actualiza cada 1 segundo
}
