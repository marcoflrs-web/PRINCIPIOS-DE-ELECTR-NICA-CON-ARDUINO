¿Qué muestra el video?

El video demuestra un sistema de medición de distancia usando el sensor ultrasónico HC-SR04 conectado a un Arduino UNO, que calcula la distancia en centímetros y la muestra en tiempo real en una pantalla LCD 16×2 con módulo I2C. En la fotografía se puede observar el circuito físico montado: el sensor HC-SR04 (con sus dos transductores circulares) en la esquina superior izquierda, el Arduino UNO al centro-derecha, y el LCD mostrando "distance: 24". El cable USB proporciona alimentación directamente desde la computadora.

Pines del HC-SR04

El HC-SR04 tiene 4 pines: VCC (5V), TRIG (disparo — pin digital de salida en el Arduino), ECHO (retorno — pin digital de entrada en el Arduino), y GND.

En el video se usa TRIG → pin 9 y ECHO → pin 10 del Arduino.

PRINCIPIO DE FUNCIONAMIENTO Física
1
Disparo (TRIG): El Arduino envía un pulso de 10 microsegundos al pin TRIG del sensor para iniciar la medición.
2
Emisión ultrasónica: El transductor TX del HC-SR04 emite 8 pulsos de sonido a 40 kHz (inaudible para humanos).
3
Reflexión (eco): Las ondas chocan con el objeto y rebotan de regreso hacia el transductor RX del sensor.
4
Medición (ECHO): El pin ECHO se pone en HIGH durante el tiempo que tardó en ir y volver. El Arduino mide ese tiempo con pulseIn(ECHO, HIGH).
5
Cálculo y display: Se aplica la fórmula para obtener la distancia y se imprime en el LCD.
distancia (cm) = duracion × 0.034 / 2
velocidad del sonido ≈ 343 m/s = 0.0343 cm/µs · se divide entre 2 porque el sonido hace el recorrido de ida y vuelta
CÓDIGO ARDUINO Sketch

Código completo — HC-SR04 + LCD I2C

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Pines del sensor HC-SR04
#define TRIG_PIN  9
#define ECHO_PIN  10

// LCD en dirección I2C 0x27, 16 columnas, 2 filas
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);

  lcd.init();        // Inicializa el LCD
  lcd.backlight();   // Enciende la retroiluminación
}

void loop() {
  // 1. Disparo: pulso de 10 µs en TRIG
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  // 2. Medir duración del pulso ECHO
  long duracion = pulseIn(ECHO_PIN, HIGH);

  // 3. Calcular distancia en cm
  float distancia = duracion * 0.034 / 2.0;

  // 4. Mostrar en LCD
  lcd.setCursor(0, 0);
  lcd.print("distance: ");
  lcd.print((int)distancia);

  lcd.setCursor(0, 1);
  lcd.print("cm          ");  // espacios para limpiar

  delay(500);  // actualiza cada 0.5 segundos
}

Conexión I2C del LCD

El módulo I2C (PCF8574) soldado en la parte trasera del LCD permite reducir las conexiones de 16 cables a solo 4: VCC, GND, SDA y SCL. En el Arduino UNO, SDA corresponde al pin A4 y SCL al pin A5. No es necesario ningún resistor adicional ya que el módulo I2C incluye sus propias resistencias de pull-up.
