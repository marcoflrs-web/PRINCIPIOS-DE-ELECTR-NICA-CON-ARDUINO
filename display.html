¿QUÉ ES EL LCD 16×2? Pantalla de cristal líquido

Visión general del módulo

Descripción del módulo

El LCD 16×2 (Liquid Crystal Display) es una pantalla de cristal líquido que puede mostrar 16 caracteres por fila en 2 filas, dando un total de 32 caracteres simultáneos. Cada carácter se forma con una matriz de 5×8 píxeles. Es uno de los componentes más utilizados con Arduino para mostrar información de sensores, menús o mensajes de estado.

PROTOCOLO I2C Comunicación serial

¿Cómo funciona el I2C?

1
Solo 2 cables de datos: El protocolo I2C usa únicamente SDA (datos) y SCL (reloj) para comunicarse con múltiples dispositivos al mismo tiempo en el mismo bus.
2
Dirección única: Cada dispositivo I2C tiene una dirección hexadecimal única (0x27 o 0x3F para el LCD). El Arduino llama a esa dirección para comunicarse con él.
3
Maestro / Esclavo: El Arduino actúa como maestro. El LCD con su módulo I2C es el esclavo. Solo el maestro inicia la comunicación.
4
Resistencias pull-up: Las líneas SDA y SCL necesitan resistencias de 4.7 kΩ a VCC. El módulo I2C del LCD ya las incluye integradas, por lo que no se necesitan agregar externamente.
5
Velocidad: El I2C en modo estándar opera a 100 kbps y en modo rápido a 400 kbps. Para el LCD es más que suficiente.

Sin I2C (modo paralelo)

El LCD HD44780 sin módulo I2C requiere conectar hasta 12 pines de Arduino: RS, RW, E, D0–D7. Esto ocupa casi todos los pines de un Arduino UNO y hace el cableado muy complicado.

Con I2C (modo serial)

Con el módulo I2C solo se usan 4 cables: VCC, GND, SDA y SCL. Libera 8 pines de Arduino y simplifica enormemente el montaje en protoboard o PCB.

Sistema de coordenadas del LCD

El cursor se posiciona con lcd.setCursor(columna, fila). La columna va de 0 a 15 (16 posiciones) y la fila es 0 o 1 (dos filas). Por ejemplo, lcd.setCursor(5, 1) coloca el cursor en la columna 6 de la segunda fila. Si escribes más caracteres de los que caben en la fila, el texto se corta — no pasa a la siguiente línea automáticamente.

CÓDIGO ARDUINO Sketches

Código básico — Hola Mundo en LCD I2C

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Dirección I2C: 0x27 (más común) o 0x3F
// Columnas: 16 | Filas: 2
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();          // Inicializa el módulo I2C
  lcd.backlight();     // Enciende la luz de fondo

  lcd.setCursor(0, 0);  // Columna 0, Fila 0 (primera fila)
  lcd.print("Hola Mundo!");

  lcd.setCursor(0, 1);  // Columna 0, Fila 1 (segunda fila)
  lcd.print("Arduino LCD");
}

void loop() {
  // Nada aquí — el texto se mantiene en pantalla
}

Código avanzado — Mostrar valor de un sensor analógico

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

#define SENSOR_PIN A0   // Potenciómetro o sensor analógico

void setup() {
  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Valor sensor:");
}

void loop() {
  int valor = analogRead(SENSOR_PIN);  // Lee 0-1023
  float voltaje = valor * (5.0 / 1023.0); // Convierte a voltios

  lcd.setCursor(0, 1);            // Segunda fila
  lcd.print(voltaje, 2);           // Imprime con 2 decimales
  lcd.print(" V      ");          // Espacios limpian dígitos viejos

  delay(300);  // Actualiza cada 0.3 s
}

Código extra — Texto desplazable (scroll)

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.print("Texto scroll!");
}

void loop() {
  // Desplaza a la izquierda 16 veces
  for (int i = 0; i < 16; i++) {
    lcd.scrollDisplayLeft();
    delay(300);
  }
  // Desplaza a la derecha 16 veces
  for (int i = 0; i < 16; i++) {
    lcd.scrollDisplayRight();
    delay(300);
  }
}

Memoria CGRAM — Caracteres personalizados

El LCD HD44780 tiene 8 espacios en su memoria CGRAM para guardar caracteres creados por el usuario. Cada carácter es una matriz de 5 columnas × 8 filas de píxeles. Se definen con un array de bytes y se cargan con lcd.createChar(). Después se imprimen con lcd.write(). Son muy útiles para crear iconos de temperatura, batería, señal, etc.

Ejemplo — Carácter personalizado (corazón)

// Definición del carácter corazón (5×8 píxeles)
byte corazon[8] = {
  0b00000,
  0b01010,
  0b11111,
  0b11111,
  0b01110,
  0b00100,
  0b00000,
  0b00000
};

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.createChar(0, corazon);  // Guarda en posición 0
  lcd.setCursor(0, 0);
  lcd.write(0);                  // Imprime el corazón
  lcd.print(" Te quiero!");
}
✅

Buena práctica: En lugar de usar lcd.clear() en cada iteración del loop() (causa parpadeo), es mejor imprimir espacios al final de tus cadenas para sobreescribir caracteres anteriores. Ejemplo: lcd.print(valor); lcd.print(" ");
